System design

A modular stack for agents, models, and runtime control.

OpenJarvis is designed as a complete local AI stack: models, inference engines, memory systems, tools, and agent orchestration all fit under one configurable framework. The result is a system that is adaptable for personal AI assistants, research workflows, coding copilots, and autonomous task execution.
